I run release engineering, CI and observability for Carbonio at Zextras, and I keep a homelab where I try things before they reach work.

Most of what I build is small infrastructure tooling: GitHub managed from YAML, OpenTelemetry exporters and Grafana dashboards. I keep it maintained, tested and documented. When something upstream gets in the way, I send the fix back: Grafana, the Grafana Tempo Helm chart, zot, Apache Camel and awesome-prometheus-alerts have merged changes of mine.

  • Release engineering: packaging, Jenkins pipelines and semantic-release for the Carbonio services.
  • Observability: OpenTelemetry exporters and Grafana dashboards for GitHub and Jenkins.
  • GitHub as code: a Terraform module that manages a GitHub organization from YAML.
  • Homelab: Kubernetes with k3s and Flux, Proxmox and AWS managed with OpenTofu, OPNsense.
